\section*{Why this document exists}
Every result below used a per-seed random pair set: seed $s$ drew its own (start, goal)
pairs via \texttt{default\_rng(s)}, so seed-to-seed spread confounded task difficulty with
CEM's own sampling noise. This is why the phase-6 protocol switched to one fixed 200-task
set shared by every seed (see \texttt{main.tex}, \S\S ``Fixed task set''). Everything here
predates that switch and is kept only as a reference for how the earlier sweeps (objective
choice, graph/lookahead knobs, executor fixes, critic weight and combinations) narrowed down
to the finalists that were then re-run under the fixed-task protocol. Do not cite success
rates from this document as the headline numbers --- use \texttt{main.tex} instead.
